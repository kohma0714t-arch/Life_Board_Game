# 🗺️ Life Board 3Dマップ＆物件購入UIリニューアル設計書

## 1. 物件購入ダイアログの「最小化＆マップ見渡し」UX仕様

添付画像（`media_1793601689801_f5c063b7.jpg`）で指摘された「画面中央を塞いで周囲のマップが見えない問題」を解消する設計。

### 1.1 状態管理
`UIManager` に `isPropertyModalMinimized: boolean`（デフォルト `false`）を追加。
- 物件マス停止時にモーダルが表示された際、ヘッダー右上に **「🔍 マップを見渡す（最小化）」** ボタンを配置。
- 最小化ボタンを押すと、画面中央のダイアログが画面右下の **「コンパクトな物件購入ドック（トイカード）」** にスムーズに折りたたまれる。
- 最小化中はモーダルの背景暗幕（`.modal-backdrop`）が解除され、**マウスドラッグでの3Dマップ旋回・ズーム・他プレイヤー位置確認**が自由に可能。
- 最小化ドック上の「🔍 詳細を開く」ボタン、またはドック内の「購入する」「見送る」ボタンを直接押すことで即座にアクションを実行可能。

### 1.2 ビジュアルデザイン（トイ・アイソメトリック化）
- OS絵文字（`🏠`）を廃止し、専用SVGアイコン（`GameIcons.pawn` / 家・コインアイコン）へ差し替え。
- コンテナを `.toy-panel-slab`（12pxの立体影と白フチ）に刷新。
- 「購入する」「見送る」ボタンを `.toy-btn-gold` / `.toy-btn-white` へ刷新し、押し込みアニメーションを適用。

## 2. 3Dマップデザインのジオラマ・アイソメトリック化仕様

参考画像（『Monopoly GO』調の青空に浮かぶ浮島ジオラマ）に基づき、3Dシーンをリニューアルする。

### 2.1 浮島ベース（Island Slab）
- 単調な平坦面から、**厚みのある2段の立体浮島ベース（上段：鮮やかなライムグリーン芝生、下段：パープル／ストーン層、側面のベベル）**を配置。
- 四隅に丸みを持たせ、おもちゃのジオラマ台座としてのソリッド感を強調。

### 2.2 立体トイブロック・マス（Chunky Tiles）
- 各マス（タイル）を厚み `0.45` の立体ブロックに変更。
- 上面にホワイトストローク（白フチ）と、グループごとの鮮やかなパステル・トイカラー（グリーンヒルズ、サンシャイン、アクアベイなど）を適用。
- マス同士をつなぐ道（道路・歩道）をホワイトのクリーンなストライプで縁取る。

### 2.3 3Dミニチュア建築（Toy Buildings）の強化
- 物件購入時およびレベルアップ（Lv1〜Lv3）時にマスの上に建つミニチュア建築を、参考画像のような「トイタウンのカラフルな家・ビル・ショップ」として鮮やかに表示。
- 所有プレイヤーのテーマカラーフラッグが屋根にはためく。

### 2.4 ボード中央のアイソメトリック・ランドマーク
- 参考画像の中央にある「青いクエスチョンカードの立体デッキ（?カード山札）」を3Dモデルとして中央の芝生に配置。
- 四隅にミニチュアの木（トイ・ツリー）や街灯を配置し、箱庭感を高める。
